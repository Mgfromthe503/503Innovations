# 503Innovations

Developer landing page for **mgfromthe503** — hosted on GitHub Pages.

## Live Site

**https://mgfromthe503.github.io/503Innovations/**

## Purpose

This site serves as the required "developer website" for Google Play Console organization account verification. It displays:

- Published apps (The Ice Cream Man)
- Tech stack
- Contact links (GitHub, Play Store)

## Deployment

1. Push to `main` branch of `mgfromthe503/503Innovations` repo
2. Enable GitHub Pages: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` → Folder: `/ (root)`
3. Site builds automatically at the URL above

## Local Preview

Open `index.html` directly in a browser, or serve locally:

```bash
npx serve .
# or
python3 -m http.server 8000
```
